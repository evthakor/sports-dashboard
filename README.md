# sports-dashboard
This is a Java command line sports dashboard intended to display upcoming games for your favorite teams.


## Project Goal
I am a huge sports fan, and it can become difficult to manage all my favorite teams with them having different schedules and scores. This dashboard will bring your favorite teams' schedule and scores into one place. 

## MVP
-Ask user for the sports teams the want to display 
-Use API to retrieve sports team info
-Display games/scores in dashboard

## Future Plans
-Use multiple sports and leagues
-Save teams selected by user between sessions
-Display standings

-Interface: Command Line Menu
-API Requests: JAVA's HTTP-client
-JSON Parsing: GSON
-Data Source: TheSportsDB API
-Tools: IntellijIdea , GIT, curl
